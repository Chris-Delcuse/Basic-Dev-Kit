There is no good or bad code, what is needed are functional and responsive apps.

Managing the `[VAR-LINK]` menu is also a part of development, for example: a ti-89 package cannot exceed 4 to 5 files, because when expanded, the entire machine tree disappears before the user's eyes.

To the extreme opposite, without a `APPS` Folder & subtancial logithec, an application optimized into a single file could appear to the user as a variable to clean up.

So for students, it is crucial to build common structures and therefore a development team that makes technical choices, while the environment is favorable. ( family support, finance...)
