**THEMATIC FOLDER**


There is no good or bad code, what is needed are functional and responsive apps.

Managing the `[VAR-LINK]` menu is also a part of development, for example: a ti-89 package cannot exceed 4 to 5 files, because when expanded, the entire machine tree disappears before the user's eyes.

![Screenshot](https://raw.githubusercontent.com/Chris-Delcuse/Basic_DevKit/refs/heads/main/Releases/Var-link1.png)

To the extreme opposite, without a `APPS` Folder & a subtancial logitech, an application optimized into a single file could appear to the user as a variable to clean up.

![Screenshot](https://raw.githubusercontent.com/Chris-Delcuse/Basic_DevKit/refs/heads/main/Releases/var-link2.png)

So it's crucial to offer common structures but make technical choices on an individual basis.
